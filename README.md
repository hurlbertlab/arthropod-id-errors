This repository includes the data and code associated with the following publication:

Hurlbert, A. H. and E. Weaver. 2026. Are the data buggy? Sources and magnitudes of error in an arthropod citizen science project. Citizen Science: Theory and Practice 11(1): 33, pp.1-14. https://doi.org/10.5334/cstp.1012

## File Organization  
**`code` folder**  
* `error_analysis.r` - script for full analysis in the manuscript  

**`data` folder**  
* `2025-12-12_ArthropodSighting.csv` - Caterpillars Count! arthropod sighting table as of 12 December 2025.  
* `2025-12-12_Survey.csv` - Caterpillars Count! survey event table. 'ID' field links to 'SurveyFK' in ArthropodSighting table as of 12 December 2025.  
* `2025-12-12_ExpertIdentification.csv` - Taxonomic identifications of arthropod photos submitted with Caterpillars Count! surveys by users on iNaturalist as of 12 December 2025. 'ArthropodSightingFK' links to 'ID' in ArthropodSighting table.  
* `2025-12-12_VirtualSurveyScore.csv` - Virtual Survey game scores and subscores.  
* `raw_length_estimates.csv` - Length estimates of arthropod specimens by users from three treatment groups (control with no aids, knowledge of thumbnail width, and user of a ruler).

**`Figures` folder**  
* Manuscript figures generated by `error_analysis.r` script (Figures 3-7)
